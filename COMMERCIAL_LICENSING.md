# Commercial Licensing

**Short answer:** the repository is public, but it is not a giveaway. Code is
AGPL-3.0-only and the book is CC BY-NC-SA 4.0. If your use cannot live inside
those terms, ask for a commercial proprietary license at
**research@twistpool.org**.

---

## When you do *not* need a commercial license

You may use the repository freely, including inside a company, when you comply
with the public licenses:

* You run or modify the code internally and do not expose a modified version
  through a network to users who are not your employees, or you do expose it
  and you offer those users the Corresponding Source as AGPL §13 requires.
* You keep modification notices, license headers, and the copyright notice.
* You share or adapt the book for non-commercial purposes with attribution and
  the same CC BY-NC-SA 4.0 terms.

Research, teaching, personal study, and non-commercial publication are
explicitly welcome. The Reader's Contract in the book exists so you can verify
every number yourself; that path is free.

## When you should ask

Write to us if any of these apply:

* a hosted or API service built from the code, where you cannot publish the
  source of your modified version to its users;
* embedding the code in a closed product, appliance, or firmware;
* redistributing the book, chapters, figures, or translations as part of a
  paid product, course, paywall, or consultancy deliverable;
* using the project names or marks in branding or a public claim of
  endorsement;
* wanting a patent covenant, sublicensing rights, support, or a specific
  territory or term.

## What the conversation covers

A commercial license is negotiated separately from this repository. Depending
on the use case it can cover the AGPL source-disclosure and notice obligations,
commercial use of the book text and figures, sublicensing, named-entity rights,
and a written patent covenant. Terms, price, duration, and territory are set in
the signed agreement. **Nothing on this page grants any of those rights by
itself**, and no price or obligation is promised here.

Include in your message: organisation, use case, deployment model (internal,
hosted, embedded, redistributed), whether the book text is involved, and the
countries/territories concerned. We reply to licensing enquiries at
**research@twistpool.org**; use `SECURITY.md` for security reports instead.

## Enforcement posture

We would rather have a conversation than a dispute. If you are unsure whether
your use is compliant, ask before shipping. If you receive a notice from us,
pause the disputed use and write to the address above; we will state the exact
file, license term, and requested remedy in writing.
